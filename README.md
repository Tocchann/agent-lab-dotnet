## 🎯 What You'll Learn

This interactive lab teaches **GitHub Copilot Agent Mode** through a practical Social Bingo game. You'll master:

| Skill | What You Do |
|-------|-----------|
| **Context Engineering** | Teach AI about your codebase with custom instructions |
| **Agentic Primitives** | Use background agents, cloud agents, and multi-stage workflows |
| **Design-First Development** | Iterate on UI with AI while you guide the vision |
| **Test-Driven Development** | Build features test-first using AI agents |
| **Multi-Agent Orchestration** | Chain agents together for complex tasks |

**Outcome:** You'll understand how to leverage AI agents to accelerate development while maintaining control and quality.

## 🎮 The Game: Social Bingo

Find people in the room who match the bingo prompts. Get 5 in a row (horizontal, vertical, or diagonal) to win!

Perfect for:
- 🤝 In-person tech mixers and meetups
- 🏢 Team building events  
- 🎓 Conferences and workshops
- 💬 Community icebreakers

**Customizable questions** → Use the Quiz Master agent to generate themes for any audience.

## � Quick Start

### Option 1: GitHub Codespaces (Fastest)

1. Open [your repo on GitHub](https://github.com)
2. Click **Code** → **Codespaces** → **Create codespace on main**
3. Wait for setup to complete
4. Run:
   ```bash
   cd SocOps
   dotnet run
   ```

### Option 2: Local Development

```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/your-soc-ops-repo.git
cd your-soc-ops-repo

# Run the app
cd SocOps
dotnet run
```

The app will open at `http://localhost:5166`

### Build for Production

```bash
cd SocOps
dotnet build
```

Deploys automatically to GitHub Pages on push to `main`.
